# LifeOS

Домашний сервер `matrix` (Xeon E5-2680 v4, Ubuntu 24.04) как личный ассистент: финансы, здоровье, спорт, планирование, работа, обучение.

В репозитории только инфраструктура и код. Личные данные (выписки, планы, анализы) в git не попадают.

| Этап | Каталог | Статус |
|---|---|---|
| 1. Matrix + push + бэкапы | [`infra/matrix`](infra/matrix/README.md) | готов к установке |
| 2. Бот-оркестратор, календарь, брифы | `bot/` | следующий |

## Обновление на сервере
```bash
cd /opt/lifeos && git pull
```
