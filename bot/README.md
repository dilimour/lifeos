# LifeOS-бот — этап 2

Бот `@lifeos:dilimour.online` создаёт пространство **«Моя жизнь»** и комнаты по сферам, отвечает только владельцу (`@john`). Данные — в отдельной базе `lifeos` в том же Postgres. Комнаты без шифрования: сервер свой, без федерации.

| Комната | Что умеет |
|---|---|
| Сводки | утренний план (08:45) и вечерний итог (21:00); вручную — `план`, `итог` |
| Финансы | `450 кафе обед`, `+98000 зарплата`, `бюджет`, `копилка 15000`, импорт PDF-выписки Т-Банка (перетащить файл) |
| Здоровье | `91.4` — вес, `вес` — динамика и прогноз, любой текст — дневник (кожа, сон, еда) |
| Спорт | `A` / `B` — тренировка дня, `присед 3x5 60` — подходы, `программа`, `история` |
| Работа | вставить список задач из Jira, `задачи`, `готово OMS-12` |
| Обучение | `45 k8s`, `1ч30 python`, `неделя` |
| Досуг | идеи и планы, `список` |

Везде работают `помощь` и `отмена`.

## Установка
```bash
cd /opt/lifeos && git pull
cd infra/matrix && ./bot-setup.sh
```
Скрипт добавит пароли в `.env`, создаст базу и пользователя бота, скопирует `bot/config.example.yaml` в `bot/local/config.yaml` и запустит контейнер. В Element появятся приглашения — прими приглашение в «Моя жизнь» и в комнаты.

Чтобы импорт выписок отличал ипотеку от прочих переводов, впиши свой номер в `.env`: `LIFEOS_OWN_PHONE=+7918…` (как в выписке), затем `docker compose up -d bot`.

## Личные настройки
`bot/local/config.yaml` (не в git): лимиты бюджета, цель копилки, цель по весу, дни тренировок и программа, часы обучения в неделю, правила импорта выписок. После правки: `docker compose restart bot`.

## Обновление и логи
```bash
cd /opt/lifeos && git pull && cd infra/matrix && docker compose up -d --build bot
docker compose logs -f bot
```
